<details>
<summary><strong>How I work</strong></summary>

<br />

1. **Frame the problem** — understand the user, constraints, and decision the system should support.
2. **Design the spine** — define the data model, interfaces, boundaries, and failure cases.
3. **Build in vertical slices** — connect interface, API, data, and validation early.
4. **Make it trustworthy** — add clear states, explainable outputs, review paths, and useful documentation.
5. **Refine the experience** — remove friction, improve clarity, and keep the system maintainable.
