## Featured work

### [DRIFT — Drone Infrastructure Inspector](https://github.com/RidhimaKulashriz/DRIFT)
**React · Node.js · Express · tRPC · PostgreSQL · Drizzle · Python · YOLO · Roboflow**

A full-stack inspection platform for drone evidence and infrastructure review. The system spans **9 operational workspaces**, a **12-entity-group data model**, multi-model detection, GPS/EXIF extraction, geospatial correlation, severity scoring, PDF reporting, authenticated ingestion, and live SSE updates.

### [DelhiCanopy AI — Urban Climate Intelligence](https://github.com/RidhimaKulashriz/Delhi-Canopy-Sambhav)
**React · TypeScript · Vite · TanStack Query · Leaflet · Supabase · ESP32**

A geospatial platform for satellite-derived green-cover data, heat-risk analytics, and computer-vision-based tree-loss alerts across Delhi wards. Includes **TrustOps**, a six-stage decision-quality workflow, plus a field-instrument prototype for PM1, PM2.5, PM10, and NO₂ monitoring.

### [StockP — Financial Analytics Platform](https://github.com/RidhimaKulashriz/stockp)
**React · Material UI · Chart.js · Express · MongoDB · Passport · JWT**

A three-service full-stack trading experience with a marketing site, authenticated dashboard, REST API, JWT/Passport security, and data-rich Chart.js visualizations.

### [Gov RAG AI — Government Query System](https://github.com/RidhimaKulashriz/gov-rag-ai)
**LangChain · Vector databases · Embeddings · LLMs**

A retrieval-augmented generation pipeline that combines government datasets, semantic search, vector embeddings, and an LLM backend for natural-language querying.

### [Guardian AI — Smart Farm Security](https://github.com/RidhimaKulashriz/guardian_ai)
**Python · YOLOv8 · Raspberry Pi · Arduino**

An edge computer-vision system for real-time animal detection at farm perimeters with hardware-triggered alerts for automated surveillance.
